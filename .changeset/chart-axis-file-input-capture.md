### Added

- **ScatterChart**: Expose `stacked` and `index-axis`, matching LineChart and BubbleChart. Run `kigumi update` to pick them up in installed components.
- **FileInput**: Expose `capture` (`user` | `environment`), which opens the front or rear camera on phones and tablets when `accept` names an image, video or audio type.
