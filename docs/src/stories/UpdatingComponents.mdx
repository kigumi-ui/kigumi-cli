        <h4 className="wa-heading-m">What is the .kigumi/ directory?</h4>
        <p className="wa-caption-m">
          The <code>.kigumi/snapshots/</code> directory stores a copy of the template
          output at install time. It should be committed to git so your whole team gets
          consistent update behavior.
        </p>

        <h4 className="wa-heading-m">I installed components before the update feature existed</h4>
        <p className="wa-caption-m">
          Legacy components (no snapshot) still work. If the file matches the current
          template, a snapshot is created automatically. If it differs, you'll be prompted
          to create one — this enables three-way merges for all future updates.
        </p>

        <h4 className="wa-heading-m">What about community registry components?</h4>
        <p className="wa-caption-m">
          Components installed via <code>--from</code> are downloaded as raw files,
          not generated from templates. They don't get snapshots and are skipped by
          the update command.
        </p>

        <h4 className="wa-heading-m">Can I regenerate a component from scratch?</h4>
        <p className="wa-caption-m">
          Yes — use <code>npx kigumi update --force</code> or{' '}
