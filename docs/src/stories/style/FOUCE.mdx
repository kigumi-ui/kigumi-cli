<DocPage
  title="Reducing FOUCE"
  description={
    <>
      The <code>.wa-cloak</code> class prevents flash of unstyled custom
      elements (FOUCE) by hiding elements until the web component registers
      itself. In production, add <code>.wa-cloak</code> to web component
      elements — they fade in once registered.
    </>
  }
>
