# Kigumi Docs

Documentation website for [Kigumi CLI](https://kigumi.style), built with Vite + React + Web Awesome Pro.

## Contributing to this docs site

This docs app uses Web Awesome Pro. After cloning the kigumi-cli repo:

1. `cp docs/.env.example docs/.env` and add your token
2. `pnpm run setup:npmrc` (generates docs/.npmrc from .env)
3. `cd docs && pnpm install && pnpm dev`

## Setup

### First Time Setup

1. **Get your Web Awesome Pro token:**
   Visit https://webawesome.com/login and copy your token

2. **Configure token** (choose one method):

   **Option A: Run the setup script (recommended)**

   ```bash
   # Create .env with your token
   cp .env.example .env
   # Edit .env and add WEBAWESOME_NPM_TOKEN=your_token

   # Generate docs/.npmrc (gitignored) from .env
   pnpm run setup:npmrc
   ```

   **Option B: Set globally** (then run setup:npmrc to generate docs/.npmrc)

   ```bash
   npm config set //npm.cloudsmith.io/fortawesome/webawesome-pro/:_authToken YOUR_TOKEN
   pnpm run setup:npmrc
   ```

3. **Install dependencies:**

   ```bash
   cd docs
   pnpm install
   ```

4. **Start development server:**
   ```bash
   pnpm dev
   ```

## How Token Authentication Works

The `docs/.npmrc` file is **gitignored** and generated by `pnpm run setup:npmrc`.
It contains the registry URL and auth token (read from `.env`).

pnpm does not use global `~/.npmrc` auth for scoped registries, so the token
must be in the project `.npmrc`. The setup script writes it there from `.env`.

## Troubleshooting

### 401 Error on install?

Your token is not configured. Run `pnpm run setup:npmrc` from the repo root (after creating `docs/.env` with your token).

### Different token per machine?

Each developer configures their own token once per machine. The setup script
detects tokens from multiple sources (in priority order):

1. `$WEBAWESOME_NPM_TOKEN` environment variable (CI/CD)
2. Global `~/.npmrc` (already configured)
3. `docs/.env` file
4. Root `.env` file
